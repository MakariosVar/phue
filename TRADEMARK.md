## Why this exists

The Apache-2.0 license grants copyright and patent rights, but **not** trademark
rights — see section 6 of the license. In practice this means:

- You **may** use, modify, and redistribute the Phue source code, including

- You **may not** use the "Phue" name or logo as the name of your own product,
  service, or fork, or in any way that implies endorsement by the Maintainer.

Copyright and trademark are separate: forking the code is fine, rebranding it
under the Phue name is not.

## Permitted uses (no permission needed)

- Truthful, descriptive references such as **"built with Phue"**,
  **"Phue framework"**, or **"compatible with Phue"**.
- Use in articles, tutorials, talks, courses, and documentation.
- Referring to the official project and linking to its repository.
- Unmodified forks that clearly credit the project and **keep the Phue name** to
  describe their origin, while making clear they are not the official project.
- Reproducing the `NOTICE` file as required by the Apache-2.0 license.

## Uses that require permission

- Using "Phue" (or a confusingly similar name) as the name of a **modified fork**,
  product, company, or hosted service.
- Using the Phue logo or any official artwork.
- Any statement or branding that suggests your project is official, endorsed by,
  or affiliated with the Maintainer.
- Registering a domain name, social handle, or trademark that includes "Phue" in a
  way likely to cause confusion.

## Rules for forks

If you distribute a modified version:

1. **Rename it.** Pick a distinct name; do not ship it as "Phue".
2. **Keep attribution.** Retain the `NOTICE` file and the copyright/license
   notices, per Apache-2.0 section 4.
3. **Mark changes.** State prominently that you changed the files.
4. **Avoid confusion.** Make clear that your project is a fork and not the
   official Phue.

For any use not covered above, contact the Maintainer at the email listed in
`composer.json` (`authors`). Requests are handled case by case; permission for one
use does not imply permission for another.
